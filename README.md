System Monitoring is a Windows tool that can display:

CPU name
Number of cores,
CPU architecture,
RAM capacity,
Internal storage capacity.

It also lists running processes and includes a field where you can paste or type a process name to terminate it.

It is implemented using C++, Qt6, and CMake.

https://walter-wlt.itch.io/system-monitoring
